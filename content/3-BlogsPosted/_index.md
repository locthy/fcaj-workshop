# Blogs Posted
Below are the blog posts I published on the AWS Study Group ([AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj)) during my internship at Amazon Web Services Vietnam.

###  [Blog 1 - Should You Stick with Zonal NAT Gateway or Switch to Regional NAT Gateway (RNAT)?](3.1-Blog1/)
This post introduces AWS NAT Gateway's new operating mode — Regional NAT Gateway (RNAT), which allows a single NAT Gateway to automatically scale and span multiple Availability Zones within the same VPC. This advancement significantly simplifies network infrastructure management compared to the previous per-AZ NAT Gateway model.

###  [Blog 2 - BENEFITS OF REGIONAL NAT GATEWAY: SECURITY, SCALE, AND IPAM INTEGRATION](3.2-Blog2/)
This article takes a deeper look at the benefits of Regional NAT Gateway in terms of security, automatic scaling to avoid port exhaustion, and integration with VPC IPAM for controlled IP address management. The post also covers monitoring via CloudWatch and integration with traffic-inspection solutions like AWS Network Firewall.

###  [Blog 3 - WHAT IS AMAZON EVENTBRIDGE? BUILDING EVENT-DRIVEN APPS ON AWS](3.3-Blog3/)
This post introduces Amazon EventBridge — a serverless service for building event-driven architectures on AWS. The article explains the two main mechanisms, Event buses and Pipes, how they work together, and the role of EventBridge Scheduler in automating scheduled tasks.
